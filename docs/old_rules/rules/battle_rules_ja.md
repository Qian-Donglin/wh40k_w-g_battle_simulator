## 1. 戦闘エンカウンターの構造

### 戦闘ラウンド

1ラウンド＝全キャラクターが1回ずつ行動する。戦闘は以下の5ステップで進む：

| ステップ | 内容 |
|---|---|
| 1. 戦闘開始 | GM がシーンを設定。サプライズ攻撃の確認、陣形を整える |
| 2. イニシアティブ決定 | ヒーロー vs 脅威の順番を決める（§2参照） |
| 3. ターン実行 | 各キャラクターが順番にアクションを行う |
| 4. ラウンド終了 | 持続エフェクトの処理、エスカレーション確認 |
| 5. 次のラウンドへ | 戦闘が終わるまで繰り返す |

### エスカレーションティア

ラウンド数に応じて戦闘の激しさが上がる。

| ラウンド | ティア |
|---|---|
| 1–2 | Tier 1 |
| 3–4 | Tier 2 |
| 5–6 | Tier 3 |
| 7+ | Tier 4 |

## 2. イニシアティブ

### バック・アンド・フォース方式

W&G の戦闘はターン制ではなく**交互行動制**。

- **ヒーロー → 脅威（Threat）→ ヒーロー → 脅威 …** の順に交互に行動する
- ヒーロー側は誰が先に動くか各自で協議して決める
- Threat 側（GM）も任意の敵を選択して動かす
- 全ヒーローと全脅威が1回ずつ行動したら**1ラウンド終了**

### イニシアティブの先取り（Seizing Initiative）

**ヒーロー側**: Glory を 1 点消費 → 相手が行動した直後、追加で1回行動できる  
**GM 側**: Ruin を 1 点消費 → 同様に追加行動できる

### 奇襲（Ambush）

奇襲された側は最初のラウンドで行動できない。奇襲した側はすべて行動し終わったら、通常の交互行動に戻る。

## 3. キャラクター種別

| 種別 | 概要 |
|---|---|
| **ヒーロー（Heroes）** | PC。Wrath ダイスを使用。クリティカルヒット可。Glory 獲得可。Soak（傷軽減）可。 |
| **NPC** | 敵対しない GM キャラクター |
| **アドバーサリー（Adversaries）** | 名のある強敵。個別 Ruin、Wrath ダイス、クリティカルあり。Soak 可（GM が Ruin 消費）。 |
| **エリート（Elites）** | 中ボス級。Wrath ダイス、クリティカルあり。個別 Ruin なし。Soak 可（GM が Ruin 消費）。 |
| **モンストラス・クリーチャー** | Fear/Pinned/Staggered 無効。特殊 Ruin アビリティを持つ場合あり。 |
| **トループ（Troops）** | 一般雑兵。個別 Ruin なし、クリティカルなし、Soak 不可。Shock 0 で即死除去。 |

### 各種別の特性まとめ

| 特性 | ヒーロー | アドバーサリー | エリート | モンストラス | トループ |
|---|:---:|:---:|:---:|:---:|:---:|
| Wrath ダイス | ✓ | ✓ | ✓ | ✓ | ✗ |
| クリティカルヒット | ✓ | ✓ | ✓ | ✓ | ✗ |
| Soak | ✓ | ✓(Ruin) | ✓(Ruin) | 場合による | ✗ |
| Shock=0で死亡 | ✗ | ✗ | ✗ | ✗ | ✓ |
| 個別 Ruin | ✗ | ✓ | ✗ | ✗ | ✗ |

## 4. モブ（集団）ルール

同一のトループが複数体まとまった集団を**モブ**と呼ぶ。

### モブの攻撃

- **アシスト上限**: 最大でモブの半数がメインアタッカーをアシストできる（エスカレーションティアでキャップ）
- **追加ダイス**: 1体アシストするごとに攻撃プールに +1d

### モブへの攻撃

- 1体を対象にするのと同様に攻撃できる
- 追加で1体ずつ対象を増やすごとに **+2DN**

### モブへのダメージ

- Shock がモブの「1体分の Shock 総計」に達するたびに、その分の Shock を消費して**1体除去**
- 例：1体の Shock 上限が 4 のモブに 8 Shock → 2体除去

## 5. サイズカテゴリ

| サイズ | 例 | 命中への影響 | 隠密・索敵への影響 |
|---|---|---|---|
| Tiny（極小） | サーボスカル、スノットリング | 攻撃側に **+2DN**（当てにくい） | 索敵側に **+2DN**（見つけにくい） |
| Small（小） | ガン・ドローン、グロット | 攻撃側に **+1DN** | 索敵側に **+1DN** |

| Huge（巨大） | ドレッドノート、レイスロード | 攻撃側に **+2d** | 索敵側に **+2d** |
| Gargantuan（超巨大） | グレイターデーモン、ランドレイダー | 攻撃側に **+3d** | 索敵側に **+3d** |

## 6. アクションと移動

### 1ターンにできること

| 種別 | 数 |
|---|---|
| 移動アクション | 1回 |
| 通常アクション | 1回 |
| シンプルアクション | 最大2回 |
| フリーアクション | 制限なし |
| **最大合計**（マルチアクション使用時） | 3アクション |

### アクション種別

| 種別 | 説明・例 |
|---|---|
| **フリー** | いつでも実行可能（コストなし）。立ち上がる、叫ぶ等 |
| **シンプル** | 短い行動。会話、スイッチ操作等 |
| **コンバット** | 攻撃、サイキック発動等 |
| **フル** | ターン全体を消費する行動 |
| **ルーイン・アクション** | 特殊 NPC 専用。1 Ruin を消費して発動 |

### 移動の種類

| 種別 | 速度 | 条件・注意 |
|---|---|---|
| 標準移動 | Speed まで | 基本移動 |
| ランニング | Speed ×2 | アクション消費 |
| スプリント | Speed ×2 | アクション消費、直線のみ、次ターンまで Defence -2 |
| 水泳 | Speed の半分 | — |
| ジャンプ | Str または Ag ×3m | — |
| タクティカル・アドバンス | Speed の半分 | カバーからカバーへ、Defence ボーナス維持 |
| 飛行 | 記載速度または Speed | — |
| クロール（這い移動） | Speed の半分 | 伏せ状態のみ |
| クライミング | Speed の半分/アクション | — |

### 地形と遮蔽

- **困難地形**: 移動速度が半分
- **遮蔽（Cover）**:
  - 半分未満が隠れている → Defence **+1**
  - 半分以上が隠れている → Defence **+2**

## 7. 攻撃ロールの手順

攻撃は以下の8ステップで解決する。

```
ステップ1: ダイスプールの組み立て
           属性 + スキル + 装備ボーナス

ステップ2: ダイスを振る
           1–3 = 失敗
           4–5 = 1アイコン（成功1個）
           6   = エグザルテッド（2アイコン）
           ※ Wrath ダイスは1個を必ず含める

ステップ3: アイコン数と Defence を比較
           アイコン ≥ Defence → 命中

ステップ4: エグザルテッドアイコンをシフト
           Defence ちょうどのアイコンを維持しつつ、
           余分なエグザルテッドアイコンをダメージプールへ移動

ステップ5: ダメージダイスを振る
           （シフトしたアイコン数 + 武器の +ED）分をロール

ステップ6: ダメージ値を Resilience と比較
           Resilience（防具/APを含む）を超えた分が Wound

ステップ7: Wrath ダイスの出目を確認
           1 → Complication（失策）
           6 → 攻撃が命中していれば Critical Hit

ステップ8: ソーク（軽減）の機会
           ヒーロー: 1 Shock + ソークロール
           NPC: GM が Ruin 1消費 + 同上
```

## 9. 近接戦闘

### 近接の基本

- **エンゲージ**: 隣接した状態。エンゲージ中は互いに近接攻撃のみ可能
- **Strength ボーナス**: 近接攻撃のダメージに Strength 値を加算する
- **素手攻撃（Unarmed Strike）**: Strength 値がダメージ値、+1ED

### ピストルの近接使用

- 近接エンゲージ中もピストルは使用可能
- 判定: Weapon Skill（Ballistic Skill ではない）
- Strength ボーナスなし、All-Out Attack 不可、Aim 不可

### エンゲージからの離脱

- エンゲージ状態で離れようとすると**機会攻撃**を受ける
- 機会攻撃を避けるには **Disengage アクション**を使用（§13参照）

### 奇襲攻撃

- 奇襲攻撃: **+2d** 攻撃 + **+1 ダメージダイス**

## 10. 遠距離攻撃

### 射程区分

| 距離 | 修正 |
|---|---|
| 武器射程の ½ 以内（近距離） | 攻撃側に **+1d** |
| 武器射程の ½〜1× （中距離） | 修正なし |
| 武器射程の 1×〜2× （長距離） | 攻撃側に **+2DN** |
| 武器射程の 2× 超 | 自動失敗 |

### 近接エンゲージ中への射撃

近接中のキャラを狙う場合：  
→ Wrath ダイスの出目が **1** の場合、別のランダムな近接参加者を誤射

### スキャター（着弾点のずれ）

範囲効果武器（グレネード、ミサイル等）は目標地点を指定する：
- **命中判定**: DN3 の Ballistic Skill テスト
- **失敗時**: 1d6 で方向、1d6 ×2m の距離だけずれる

## 11. リロードシステム

### 概要

弾薬は抽象化されており「シーンを通じて足りる量」として扱う。  
ヒーローはセッション開始時に**3リロード**を持つ。武器は完全装填状態でスタート。

- 通常の射撃でリロードは消費しない
- **Complication** 発生時：リロードを 1 消費する可能性がある
- リロードが **0** のときに Complication → 弾切れ

### リロードの用途

| 用途 | 消費 | 効果 |
|---|---|---|
| マルチアタック時の DN 軽減 | 1 Reload | DN を武器の Salvo 値だけ下げる |
| Salvo（連射） | 1 Reload | Salvo 値分のボーナス攻撃ダイスを得る |
| 制圧射撃（Suppressive Fire） | 1 Reload | アクションも消費（§13参照） |
| 再装填（Reloading） | 1 Reload | アクション消費で武器を再装填 |
| 特殊弾薬 | 1（1回使用） | 使用するとリロード消費 |

**Salvo 0 または「−」の武器**: Salvo や マルチアタックの DN 軽減は使用不可

## 12. 爆発物・範囲効果攻撃

### 対象数（Blast Size による）

**表4-2: 範囲効果対象数**

| サイズ | 対象数 | 例 |
|---|---|---|
| Small（小） | 1 | マイクログレネード、ハンドフレイマー |
| Medium（中） | 3 | フラググレネード、フレイマー |
| Large（大） | 5 | バトルキャノン砲弾、ヘビーフレイマー |
| Very Large（特大） | 10 | クエイクキャノン砲弾 |
| Huge（超大） | 15 | 軌道爆撃 |

- 隣接・エンゲージ中のキャラは自動的に含まれる（対象数のカウントに含まない）
- GM は状況に応じて対象数を調整できる

### 範囲攻撃への防御

Large 以下の範囲攻撃には **Full Defence** アクションで対処可能：  
→ 引き上げられた Defence が攻撃ロールを上回れば回避成功  
Very Large 以上の攻撃は回避不可

## 13. 戦闘オプション

### Aim（照準）

- 移動を犠牲にする
- 遠距離攻撃に **+1d**、または近接エンゲージへの射撃を誤射リスクなしで行える
- Prone 状態では立ち上がるときに使用不可

---

### All-Out Attack（全力攻撃）

- 近接攻撃に **+2d**
- **Defence -2**（次のターンまで）
- Multi-action との組み合わせ不可

---

### Brace（固定射撃体制）

- 移動を犠牲にする
- Heavy 武器のペナルティを無効化

---

### Called Shot（狙い撃ち）

| 対象部位 | DN ペナルティ | 追加ダメージダイス |
|---|---|---|
| 中（腕・脚） | +2DN | +1ED |
| 小（手・頭） | +4DN | +2ED |
| 極小（目・関節） | +6DN | +3ED |

- 追加ダイスは急所を狙っている場合のみ適用
- **武器を弾き飛ばす（Disarm）**: 命中すると相手は Strength テスト（DN = ダメージ値の半分）に失敗すると武器を落とす

---

### Charge（突撃）

- Speed 分まで移動 + 近接攻撃を **+1d** で行う
- 突撃移動はフル移動だが攻撃も行える

---

### Disengage（離脱）

- アクション消費
- Speed の ½ まで離れられる
- 機会攻撃を受けない

---

### Full Defence（完全防御）

- ターン全体を犠牲にする
- Initiative ロール: 各アイコン = Defence **+1**（次のターン開始まで）
- 移動は Speed の半分のみ
- Defence 最低値は 1
- **既に行動済みのターンにも宣言可能**（その場合は次のターンの行動を犠牲にする）

---

### Grapple（組み付き）

- **判定**: 対抗 Strength テスト
- **成功**: 対象が **Restrained** 状態になる
- **制限**: 片手武器のみ使用可能
- **脱出**: アクション消費 + 対抗 Strength テストに勝利
- **サイズボーナス**: 対象より 1 サイズ大きいごとに +2d
- Multi-attack と組み合わせ可能（組み付きながら攻撃）

---

### Hold Action（行動待機）

- 相手のターンを待って行動を保留
- **割り込み**: 対抗 Initiative テストに勝利すれば別キャラクターの前に割り込める
- ラウンド終了まで使わなければ消滅

---

### Multi-attack（複数攻撃）

- 追加対象1体ごとに **+2DN**
- 1回のロールで全対象に適用
- クリティカルは**1体を選んで**適用
- 近接では全対象とエンゲージしている必要あり
- Reload 消費で DN を武器の Salvo 値だけ下げられる
- Salvo「−」の武器はマルチアタック不可

---

### Multi-action（複数行動）

- 追加アクション1つごとに全ロールに **+2DN**
- 宣言はロール前に行う
- 同じアクションを複数回繰り返すことはできない
- 増加した DN は全アクションに適用

---

### Salvo（連射）

- 1 Reload 消費
- Salvo 値分のボーナス攻撃ダイスを得る
- Multi-attack との組み合わせ不可
- Salvo 0 または「−」の武器は使用不可

---

### Suppressive Fire（制圧射撃）

- 1 Reload + アクション消費
- 判定: Ballistic Skill → **インタラクション攻撃**として対象の Resolve に対して行う
- ダメージなし（Player's Call で例外あり）
- Wrath ダイスの 6 でもクリティカルは発生しない
- 命中した対象は **Pinned** 状態になる

---

## 14. ダメージ処理

### ダメージ vs Resilience

| 結果 | 効果 |
|---|---|
| ダメージ < Resilience | 効果なし |
| ダメージ = Resilience | **1d3 Shock** |
| ダメージ > Resilience | 超過 1 点ごとに **1 Wound** |

- 近接攻撃: Strength 値をダメージに加算
- 複数対象: 1回のロール結果を全対象に適用

### Shock（疲弊）

- Shock が 0 になると**疲弊（Exhausted）**状態
- **回復**: アクション + Wrath 1消費 → 1d3+3 Shock 回復
- **トループ**: Shock 0 = 戦闘不能・除去
- **モブ**: 1体分の Shock 合計に達するたびに 1体除去

### Wound（負傷）

| 種別 | Wound 0 の結果 |
|---|---|
| ヒーロー | 意識不明（大ダメージなら即死） |
| アドバーサリー | 意識不明または死亡（GM 判断） |
| エリート・トループ・モンスター | 即死 |

**負傷ペナルティ**:  
- **軽傷（Lightly Wounded）**: 全 Wound の半分以下が失われている → 全判定 **+1DN**  
- **重傷（Heavily Wounded）**: 全 Wound の半分超が失われている → 全判定 **+2DN**

### ソーク（Soak）

1. **1 Shock を消費**（ヒーロー自身）、または GM が **1 Ruin 消費**（NPC）
2. **ソークロール**: テストではない（Wrath ダイスなし、DN なし）
   - 通常アイコン: Wound 1 → Shock 1 に変換
   - エグザルテッドアイコン: Wound 2 → Shock 2 に変換
3. 残りの Wound はそのまま適用
4. Wrath でソークの失敗を振り直し可能

**トループはソーク不可**。  
**モータル・ウーンドは通常ソーク不可**（一部の装備で例外あり）。  
Wound をいくつか回復すると意識不明状態が解除される。

## 15. クリティカルヒット

### 発生条件

**Wrath ダイスの出目が 6** かつ攻撃が命中

- ダメージが Resilience 以下でも、クリティカル効果は適用 + 1 Wound が加わる

### Wrath デッキ

## 16. インタラクション攻撃

### 概要

物理ダメージなしで相手を動揺・妨害・制圧する攻撃。

### 使用スキルと射程

| スキル | 射程条件 |
|---|---|
| Athletics | 近接エンゲージ中のみ |
| Deception | 視認・会話可能な範囲 |
| Intimidate | 視認・会話可能な範囲 |
| Persuasion | 視認・会話可能な範囲 |
| Tech | Intellect 値（メートル）以内 |

### 難易度

**DN = 対象のスキル値 または Resolve のどちらか高い方**

### 効果（1つ選択）

| 効果 | 内容 |
|---|---|
| Hindered | 全判定に +1DN |
| Vulnerable | Defence -1 |

- 持続時間: ラウンド終了まで
- 超過アイコンごとに効果を強化（DN または Defence ペナルティを +1）
- **Player's Call**（3+個のエグザルテッドアイコンをシフト）: 追加効果を交渉

### モブへのインタラクション攻撃

- DN を 3 アイコン超えるごとに **追加で 1体**に効果
- Player's Call でモブ全体に効果

> Defence の最低値は常に 1

## 17. 戦闘エフェクト（状態異常）

### 一覧表

| エフェクト | 主な効果 |
|---|---|
| Bleeding | ターン終了時に 1 Mortal Wound |
| Blinded | 視覚系全判定 +4DN |
| Burning | ターン開始時 D3 Mortal Wound; Willpower DN3 or 炎効果継続 |
| Exhausted | 基本移動+1アクション+離脱のみ可能; Soak 不可 |
| Fear | 攻撃者に関連するテスト +1DN |
| Frenzied | 必ず All-Out Attack; Fear と Pinning 無効 |
| Hindered | 全判定に DN ペナルティ |
| Pinned | カバーへ移動必須; 突撃不可; 遠距離攻撃の被弾 +2DN |
| Poisoned | 毒の Toughness テスト失敗で毎ターンダメージ |
| Prone | Defence -2; 立ち上がりは移動扱い |
| Restrained | Defence -2; 次の移動アクション消失; 走れない |
| Staggered | Speed ½; 走れない・スプリント不可 |
| Terror | 攻撃者関連の全テスト +2DN; 攻撃者に近寄れない |
| Vulnerable | Defence 減少 |

### 解除方法

- **自己解除**: アクション消費 + Toughness または Willpower テスト DN3 成功
- **他者解除**: アクション消費 + Medicae または Leadership テスト DN3 成功
- 全エフェクトは**戦闘またはシーン終了**で自動解除（GM 裁量あり）

### 各エフェクトの詳細

#### Bleeding（出血）
- ターン終了時に **1 Mortal Wound**
- **停止条件**: Toughness テスト DN4 成功、または Medicae スキルによる治療
- 意識を失い Wound が 0 になると自動で終了

#### Blinded（盲目）
- 視覚を要するすべての判定（戦闘含む）に **+4DN**

#### Burning（炎上）
- ターン**開始**時に **D3 Mortal Wound**
- 加えて Willpower テスト（DN3）失敗でそのラウンド中は炎の効果が継続

#### Exhausted（疲弊）
- **発生条件**: Shock が 0 になる、または武器・サイキック・ルーインアクションで付与
- **制限**: 基本移動 + 通常アクション1つ + Disengage のみ可能。追加 Shock は Mortal Wound になる。**Soak 不可**
- **解除**: Shock が 1 以上に回復したとき

#### Fear（恐怖）
- **発生時**: Resolve テストを振る → 成功で通常行動。失敗で攻撃者への判定に **+1DN**
- **解除**: Leadership テスト
- Fear を引き起こすキャラは自身も Fear・Intimidation インタラクション攻撃に**免疫**

#### Frenzied（狂乱）
- マイナーアクション等で発動 / ターン開始時に Willpower DN3 で抵抗可能
- **発動中**: 最寄りの敵に突撃（カバーから飛び出す）; All-Out Attack 強制
- Fear と Pinning に**免疫**

#### Hindered（妨害）
- インタラクション攻撃によるもの: **+1DN**（超過アイコンで上昇）
- 他の発生源の場合はカッコ内の数値
- 持続: 1ラウンド

#### Pinned（制圧）
- **発生時**: 対象が Resolve テスト（複数の狙撃者がいれば +1DN ごとに）に失敗
- カバーを探して伏せる（強制移動）; 突撃不可; 被弾遠距離攻撃 **+2DN**
- **解除**: 味方の Leadership テスト成功 → 5m 以内の全 Pinned を解除

#### Prone（伏せ）
- Defence **-2**
- 立ち上がりは**フリーアクション**（ただし隣接する味方が移動を犠牲にして即時起こすことも可）
- 起き上がったターンは Aim などの移動犠牲の戦闘オプション使用不可

#### Poisoned（中毒）
- **毎ターン終了時**: Toughness テスト失敗で毒のダメージを受ける（毒の種類による）
- **解除**: Toughness テスト成功または Medicae による治療

#### Restrained（束縛）
- 次の移動アクションを失う（Aim などの「移動の犠牲」も不可）
- 走り・スプリント不可
- Defence **-2**

#### Staggered（よろめき）
- Speed が **½**; 走り・スプリント不可
- 持続: 1ラウンド

#### Terror（戦慄）
- 攻撃者に関連する全テストに **+2DN**; 攻撃者に近づけない
- **解除**: Leadership テスト
- Fear と Terror の免疫は連動する

#### Vulnerable（脆弱）
- Defence **-1**（インタラクション攻撃の場合は超過アイコンで上昇）
- 持続: 1ラウンド

## 19. 気絶・死亡・Defiance Check

### 意識不明（Unconscious）

Wound が 0 になったキャラクターは**意識を失い伏せ状態**になる。  
（伏せ状態の全効果を受ける）

別のキャラクターが Use Object アクションで意識不明のキャラを移動させられる（援護退避）。

### Defiance Check（抗いのチェック）

Wound が 0 の状態でターンを開始するたびに必要：

- **タイミング**: ターン開始時のフリーアクションとして行う
- **ロール**: 1d6

| 出目 | 結果 |
|---|---|
| 6 | 安定化 **かつ** Wound 1 で意識回復 |
| 4–5 | 安定化（意識不明は続くが Defiance Check 不要に） |
| 2–3 | **失敗 1回** |
| 1 | **失敗 2回** |
| 失敗 3回累計 | **死亡** |

- **Wrath の使用**: Defiance Check の振り直しは不可。ただし Wrath 1消費で結果に **+1** できる（ロール前に宣言）
- 追加ダメージを受けたときも Defiance Check が必要（ターン開始時と連続することもある）

### 失敗回数による追加負傷

| 失敗回数 | 追加効果 |
|---|---|
| 1回 | 戦闘終了後に**表4-4: Memorable Injury** をロール |
| 2回 | 戦闘終了後に**表4-5: Maiming** をロール |
| 3回 | 死亡 |

### 安定化（Stabilising）

安定化したキャラクターは意識不明のまま Defiance Check が不要になる。  
他のキャラクターが Medicae テストに成功すれば Wound 0 のキャラを安定化できる。

### 死亡（Death）

以下の場合に死亡：
- Defiance Check を3回失敗
- Annihilation（殲滅）: 1回の攻撃で最大 Wound の**2倍**を超えるダメージを受けた

## 20. 負傷テーブル

### 表4-4: Memorable Injury（記憶に残る負傷）

Defiance Check 1回失敗後、戦闘終了時にロール。

| D6 | 負傷 | エスカレーション後 |
|---|---|---|
| 1–2 | Battle Scar（戦傷跡） | Fearsome Scar（恐ろしい傷跡） |
| 3 | Focused Burn（局所的な火傷） | Severe Burn（重度火傷） |
| 4 | Broken Jaw（顎の骨折） | Missing Fingers（指欠損） |
| 5 | Twitch（痙攣） | Bad Knee（膝の損傷） |
| 6 | Torn Ear（耳の裂傷） | Nagging Wound（くすぶる傷） |

- Memorable Injury を持つキャラは **Intimidation テストに +1d**
- すでに同じ結果を持っている場合は**エスカレーション**（次段階へ）
- それ以上エスカレーションできなければ無効（ただラッキーだった）

### 表4-5: Maiming（切断・不能化）

Defiance Check 2回失敗後、戦闘終了時にロール。

| D6 | 部位 | 効果 |
|---|---|---|
| 1 | 手 | その手での装備・武器使用不可。両手なら装備全般不可 + 手を必要とする判定 **+6DN** |
| 2 | 腕 | 腕が使用不能。両腕なら装備不可 + **+6DN** |
| 3 | 足 | 足が使用不能。両足なら歩行・走行不可（這いのみ） |
| 4 | 脚 | 脚が使用不能。両脚なら歩行・走行不可（這いのみ） |
| 5 | 胴体 | 内臓損傷。Toughness テスト（Soak 含む）**+2DN** |
| 6 | 目 | 遠距離判定 **+2DN**。両目失明は視覚関連判定 **+6DN** |

**バイオニック補装**: 対応するバイオニック補装具を取得するとペナルティをすべて無効化できる（41st ミレニアムでは一般的）。

## 21. ビークル戦闘

### 基本操作

- パイロットは**移動アクション**としてビークルを操作
- ターン開始時に最大 **45°** 方向転換が可能
- その後、Cruising Speed の **2倍** まで移動できる（停止状態からは半分まで）
- 移動後にアクション・武器射撃・スタントを実行
- すべての通常戦闘オプション（Aim、Suppressive Fire 等）が使用可能

**飛行ビークル（Hover なし）**: 毎ターン少なくとも Cruising Speed の半分は移動しなければ墜落。

### スタント

アクションを消費して Pilot テストを行い、特殊行動を実行。

#### Bootleg Turn（急旋回）
- **難易度**: DN5
- 最大 **90°** 方向転換
- アイコンを 1 つシフトすると **180°** まで旋回可能

#### Evasion（回避機動）
- **難易度**: DN3
- 成功すると搭乗者全員の Defence **+1**（ラウンド終了まで）
- 追加シフトごとに Defence +1

#### Ram（体当たり）
- **難易度**: 対象の Defence 値
- 停止状態から開始の場合は使用不可
- 対象の位置まで移動 → Pilot テストに成功すると体当たり実行
- **対象へのダメージ**: ビークルの最大 Wound と同等のダメージ値を持つ近接武器で攻撃したのと同等
  - エグザルテッドアイコンをシフトして通常通りダメージを増加可能
- **ビークルへの自損**: ビークルの最大 Wound の半分（近接武器値として）
- **速度ボーナス（追加 ED）**:
  
  | 速度 | 追加ダメージダイス |
  |---|---|
  | Cruising Speed の ½ 以下 | +1ED |
  | Cruising Speed | +2ED |
  | Cruising Speed の 2× 以上 | +3ED |
  
  ※ 正面衝突の場合は追加 **+1ED**

- **ラム後の Pilot テスト**: DN1（ラム攻撃で受けた Wound 数 +1 ごと）失敗で制御不能 → Hindered(2) または Vulnerable(2)（GM 選択）

### 搭乗者への攻撃

- **Open Top** trait のビークル: 搭乗者を対象にできる。搭乗者は遮蔽から Defence **+2**
- **Sealed** ビークル: 搭乗者を対象にできない（サイキックパワー含む）

### 爆発物とビークル

- Sealed ビークルの搭乗者: Blast 武器によるダメージを受けない
- Blast 武器が Sealed ビークルにダメージを与えた場合: 搭乗者全員が **1d3 Shock**

### ビークルのリロード

- 10 Reloads を搭載（セッションごとに補充）
- 通常、ビークルのリロードは個人武器には適用されない（GM 裁量で例外あり）

### ビークルへのダメージ

- キャラクターと同様のルール
- Shock のみのダメージには**免疫**
- **軽傷**: 失った Wound が上限の半分以下 → Pilot・武器射撃テスト **+1DN**
- **重傷**: 上限の半分超 → **+2DN**（パイロットが軽傷/重傷の場合も同様、重複しない）
- クリティカルヒット時: **Wrath デッキではなく表4-6を使用**
- Wound 0 = **大破**（移動不能、全武器・システム停止、搭乗者 1d3 Shock; 遮蔽として使用可）
- 最大 Wound の **2倍** のダメージ = **完全破壊**（残骸のみ）

### ビークルのソーク

- パイロットが **Wrath 1 消費**（NPC の場合 GM が Ruin 消費）
- **判定**: Agility + Piloting ロール（Toughness ではない）
- アイコン 1 つにつき Wound 1 つを軽減
- 移動不能のビークルはソーク不可
- DN ペナルティがある場合: DN ペナルティ 1 ごとにアイコン 1 無効

### ビークルの修理

**Critical Effect の除去 / 修理**:
- Tech テスト（軽傷: DN2、重傷: DN4）
- 1時間/1テスト; 成功で Wound **1 回復**; シフトで追加 Wound 回復
- ガレージ・整備施設内では **+2d** ボーナス
- 最大 Wound まで回復すると全 Critical Effect が消える

**修理中の追加 DN**: 走行中の修理 **+1DN** / パイロット自身が修理 **+1DN**（重複可）

### 表4-6: ビークル・クリティカルヒット

| 1d6 | 効果 |
|---|---|
| 1 | **Weapon Breakdown**: 搭載武器の 1 つにコンプリケーション |
| 2 | **Spinout**: 向きがランダムに変わる; 搭乗者全員 1d3 Shock |
| 3 | **Shot Steering**: 全スタント **+2DN**; 2回目: さらに **+2DN**、Bootleg Turn 以外での旋回不可 |
| 4 | **Drive Compromised**: Cruising Speed 半減; 2回目: スタント不可、Speed ¼ |
| 5 | **Fuel Leak**: シーン終了時に燃料切れ; 2回目: 即座に完全停止 |
| 6 | **Blowout**: **+1d3 Wound** |

## 22. 武器プロファイルと特性

> 詳細な武器リスト（遠距離・近接全武器の統計値）は [`weapons_ja.md`](weapons_ja.md) を参照。

### 武器プロファイルの各項目

| 項目 | 説明 |
|------|------|
| **AP（装甲貫通）** | 命中時に対象の装甲をこの値分無視する。`*`付きは「無敵の防護（invulnerable）」には無効 |
| **ダメージ評価** | 基本ダメージ値。`+ED`は追加ダメージダイスの数 |
| **射程** | 近接=1m（一部2m）、遠距離=中距離有効射程、投擲=STR×4m |
| **サルボ** | 攻撃1回で費やす弾薬ボーナス数。`—`の場合は毎射でリロード1消費 |
| **特性** | 武器固有の特殊ルール（下記参照） |
| **価値** | 入手難度。Common → Uncommon → Rare → Very Rare → Unique |
| **キーワード** | 武器タイプ＋ファクション分類（入手制限に影響） |

---

### リロードと弾薬

弾薬は**リロード（Reloads）**という抽象リソースで管理する。

- キャラクターはセッション開始時にリロード**3個**（またはSTR÷2の高い方）を持つ
- サルボ「—」の武器は毎回の射撃でリロード1を消費する（メルタガン、フレイマー等）
- リロードが0になると遠距離攻撃ができない
- セッション開始時に適切な場所にいれば3個まで無料補充できる

#### 特殊弾薬

特殊弾薬はリロード1個分として購入・携行し、リロードが尽きるまで効果が持続する。

| 弾薬名 | 効果 |
|--------|------|
| Hellfire Bolt Rounds | 有機生命体に対して+2ED（+3ED） |
| Kraken Bolt Rounds | AP -2 |
| Manstopper Rounds | +1ED（Projectileキーワード武器のみ、Heavy不可） |
| Vengeance Bolt Rounds | Spread特性を付与し、カバーボーナスを無視 |

---

### 武器特性一覧

| 特性 | 効果の概要 |
|------|-----------|
| **Agonizing** | 傷を与えるたびに被害者は1ショックも受ける。消耗状態（Exhausted）の対象は意識不明になる |
| **Arc (X)** | 車両への攻撃時、EDボーナスが評価値（X）分追加される |
| **Assault** | 移動中でも射撃可能。Runアクション中の射撃は命中難度+2 |
| **Blast (Size)** | 1回の攻撃で複数目標にダメージ（Small/Medium/Large）。外れた場合は着弾点がずれる |
