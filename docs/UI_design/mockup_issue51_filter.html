現在の検索バーはテキスト入力欄1つのみで、武器名の部分一致検索しかできない。

03 — 特性フィルタパネルの中身（#50の5カテゴリを流用）

パネルはチェックボックス形式で、#50で確定した5カテゴリごとにグルーピングして表示する。個別の特性単位でON/OFFできる（カテゴリ単位の一括選択は持たない）。

カテゴリ選択できる特性
攻撃力・貫通 Brutal / Piercing / Melta / Rending / Concussive / Power / Force / Warp Weapon / Waaagh!
命中・範囲 Blast / Barrage / Flamer / Spread / Sniper / Sonic
運用・利便 Assault / Pistol / Rapid Fire / Reliable / Steadfast / Silent / Parry / Psyniscience / Deny the Witch
状態異常 StatusEffect（On Fire / Poison など） / Toxic
要件・リスク Heavy / Unwieldy / Supercharge

※ StatusEffect は statusEffectName ごとに個別の選択肢が並ぶ想定だが、現行データセットに実例がないためこのモックアップのパネルには含めていない。

04 — フィルタロジックの仕様

  • 武器種チップ内は OR：例）近接＋遠距離を選択 → 近接または遠距離のどちらかに該当する行を表示。
  • 特性チェック内は OR：例）Piercing＋Heavy を選択 → どちらか一方でも持っていれば表示。
  • 武器種／特性／テキスト検索の3グループ間は AND：例）武器種=遠距離、特性=Piercing、検索="bolter" → 遠距離武器 かつ Piercingを持つ かつ 名前に bolter を含む、を全て満たす行のみ表示。
  • いずれのグループも「未選択」であれば、そのグループによる絞り込みは行わない（全件通過）。
  • 条件に一致する行が0件になったら「条件に一致する装備がありません」を表示する（空状態）。
決定：グループ内OR・グループ間ANDの組み合わせで確定（一般的な複合フィルタの挙動に合わせた）。

06 — レビュー結果

  1. アイコン — 武器種アイコンの意匠はこのまま採用。弾薬アイコンは丸い弾頭（実包のような形状）に修正（本ドキュメント反映済み）。#49 の実物アーティファクトとの厳密照合は Unity 実装 (#16) 時に行う。
  2. フィルタバーの配置 — 検索ボックス・武器種チップ・特性ドロップダウンを1行にまとめる案で承認。画面幅が狭い場合の折り返しは、HTML・Unity実装のどちらでも対応する。
  3. 特性フィルタの単位 — 個別特性単位のチェックボックスのみとし、カテゴリ単位の一括ON/OFFは持たない案で承認。
  4. クリア操作 — 「すべてクリア」の一括ボタンのみとし、グループ単位のクリアボタンは持たない案で承認。
  5. フィルタロジック — 04節の「グループ内OR・グループ間AND」で確定。
