キャラクターが持つことができる武器についての定義を行う。

# 武器の種類

武器の種類は以下のように分けられる。

- 近接武器: レンジが近く、自分のSTRが攻撃力に乗る武器。近接武器で攻撃された敵は次のターン接敵している扱いとなり、一部の特性を除く遠距離武器を使用できない。
- 遠距離武器: 遠距離から攻撃できる武器。Salvoという最大連射率と、Magazineという「リロードするまでに攻撃できる回数」を持つ。Magazineが0になったらリロードが必要である。
- 単発武器: 遠距離で攻撃できるが、使用回数に制限がある武器。手榴弾やミサイルなど。

# 近接武器

以下のステータスを持つ。

- `int melee_range;` 武器の攻撃半径
- `int base_damage;` 武器の基礎ダメージ。これにSTR(アーマーなどによる補正後)の値を足したものが最終的な基礎ダメージとなる。
- `int extra_damage_dice;` 追加で振るダイスの数。ルールにも記述するが、1つのダイスごとに出目によりダメージが追加される。通常の武器なら1-3なら出目は+0、4-5なら出目は+1、6は出目は+2となる。
- `int AP;` 武器のアーマーの防御を免除する能力。ダメージ計算する際アーマーの防御性能をAP点低下させる。
- `Trait` 武器の持つ属性について。特性の一覧は後ほど記載する。

# 遠距離武器

以下のステータスを持つ。

- `int range;` 武器の射程距離。ルールにも記載するが、遠距離武器は射程距離に基づいて、BSや攻撃相手のDefenseに修正値を加える。
- `int base_damage;` 武器の基礎ダメージ。**遠距離武器はSTRを加えない**。
- `int extra_damage_dice;` 追加で振るダイスの数。ルールにも記述するが、1つのダイスごとに出目によりダメージが追加される。通常の武器なら1-3なら出目は+0、4-5なら出目は+1、6は出目は+2となる。
- `int AP;` 武器のアーマーの防御を免除する能力。ダメージ計算する際アーマーの防御性能をAP点低下させる。
- `int salvo; ` フルレートで射撃した際の弾薬消費レート。
- `int magazine; ` リロードするまでに攻撃できる回数の上限。0になるとリロードが必要。

以下のステータスを持つ。

- `int base_damage;` ベースのダメージ。
- `int extra_damage_dice;` 追加で振るダイスの数。ルールにも記述するが、1つのダイスごとに出目によりダメージが追加される。通常の武器なら1-3なら出目は+0、4-5なら出目は+1、6は出目は+2となる。
- `int AP;` 武器のアーマーの防御を免除する能力。ダメージ計算する際アーマーの防御性能をAP点低下させる。
- `int uses;` 所持数（使用可能回数）。0は無制限を表す。手榴弾・ミサイルのような単発武器は使い切りの回数として、Kraken Bolt Roundのような特殊弾薬は所持している個数としてこの値を使う。
- `Trait` 武器の持つ属性について。特性の一覧は後ほど記載する。

# 各武器や弾薬の特性

今段階ではまだテキストとして取り込んでください。のちほどルールを制定した時に、ロジックに記述して下さい。

- Assault: 移動しながら射撃しても不利なし
- Barrage: Salvo攻撃時にBlastレーティングがSalvo値分増加
- Blast (X): DN3のBallistic Skillテストで指定点を狙い、Blast範囲内の全対象に命中
- Brutal: EDの各ダイスに+1
- Concussive (X): 命中時にDN(X)のToughnessテストを強制。失敗でStaggered、ダメージがStrengthを超えるとProneにもなる
- Deny the Witch: アクションとして使用。範囲50m内の敵サイカーの能力発動を妨害・打ち消す（DN=対象能力のDN+2）
- Flamer: 直線範囲攻撃。カバー無視。直線上の全対象に命中
- Force: サイカーが使用するとウォープエネルギーが乗りフル性能を発揮。非サイカーが使うとダメージ-2。Warp Weapon特性も持つ
- Heavy (X): Braceが必要。Braceなしでは通常射撃不可
- (状態異常) (X): ダメージを与えた際、括弧内の状態異常（On Fire、Poisonなど）を標的に付与 例えば"Poision 4"
- Melta (X): Short Range以内の対象に対し追加APと追加EDを加える
- Parry: 近接戦闘でのDefenceに+1
- Piercing (AP): 常時、対象のARを減少させる装甲貫通。Invulnerableには無効
- Pistol: 近接戦闘（Engaged）中でも射撃可能
- Psyniscience: Free Actionとして使用。範囲50m内のウォープ現象・PSYKERキーワード持ちを感知
- Rapid Fire (X): Half Rangeではレーティング分のボーナスダイス。使用後Reload必要
- Reliable: シーンに1回、コンプリケーションを無視可能。修理・整備テストに+1ボーナスダイス
- Rending (X): 攻撃テストでExalted Icon（6の目）をShiftした際、Rendingレーティング分APが向上
- Silent: 音を立てずに攻撃。ステルス行動中に有用。Stealth Scoreを-3
- Sniper (X): Aim時に追加ボーナスダイス+1とSniper値分の追加ED。Short Rangeの標的にAim/Braceなしで撃つとDNがSniper値分増加
- Sonic: カバーによるDefenceボーナスを無視
- Spread: 扇状範囲への射撃が可能
- Steadfast: コンプリケーションへの安定耐性を持つ
- Supercharge: Superchargeモードで射撃可能。コンプリケーション発生時に1d6 Mortal Wounds。命中時は+3 ED。SalvoとあわせるとRisky (1)が付与（既存なら+1）
- Toxic: 命中時に毒状態を付与し、Poisoned状態のペナルティ（全テスト+2 DN）を与える
- Unwieldy (X): 攻撃のDNがUnwieldyレーティング分増加。Unwieldy(2)以下の射撃武器はBraceでDNペナルティを無視可能
- Waaagh!: オーク専用。オークがこの武器で攻撃する際+1ボーナスダイス。Wounded状態なら追加+1 ED
- Warp Weapon: サイキックエネルギー・エイリアン技術・ケイオスの力による武器。ダエモンなど非物質的な存在にも有効
- Power (X): アーマー専用特性。装備者の STR を +X として扱ってダメージ計算を行う。
