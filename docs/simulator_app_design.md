ここにシミュレーター全体でのアプリのデザインを記述する。

# 画面1: シミュレーション画面

ゲームのシミュレーション画面。これは現在の`BattlSimulator.cs`の部分に相当する。

- この中で、右上か右下で、普段は隠れているメニューを置く。
- デザインは"三"のような形で、タップするとプルダウンorプルアップメニューが現れる。
- その中で、画面2: キャラクターロードや編集画面に遷移で切る。
- 左上に、画面3のタイトル画面に戻る機能をつける。

# 画面2: キャラクターのステータス画面

キャラクターのステータス画面。
ボタンによって、値を変更できるようにする編集モードへの相互切り替えも可能。

キャラ名と、既に設定したステータスと、持っている武器や弾薬を見せることができるUIを持つ。

# 画面3: タイトル画面

シミュレーターのタイトル画面。

- 画面1のシミュレーター画面
- 画面4の装備画面
//- 画面5のキャラ特性、装備特性編集画面
//- 画面6のキャラクター編集画面

にそれぞれ遷移するボタンを、縦に並べる。

タイトルはこのプロジェクトの名前としてください。

# 画面4: 装備画面

装備(近距離武器、遠距離武器、弾薬、防具、その他装備)などについて、検索、編集、追加、削除する画面。

すべての武器は、特性を持つ。(特性のない武器も存在する)

武器の持つべきステータスは、/docs/weapon.mdを参考にする。

UIは、上部検索できるバーと、下側に検索して出てきた武器をList状に並べたものを持つ。各行の要素は、以下のものを含む。

- 装備の名前
- ダメージと、ダイスによる追加ダメージ。10+1EDのように記述する。
    - 存在しない装備は"-"で表示する。
    - 防具の場合は、例外的に"AP X"と表示。(Xは防具が提供するアーマー値)
- 装備と持つ特性。これはラベルのような表記で、横に並べる、見切れていても、その中で横スクロールできるなら構わない。
- 遠距離武器限定で、"2/10"のようにSalvoとArmoの値を追加する。

装備は、追加、削除、編集ができる。

編集UIは、値の編集は1行目に特徴以外の値のすべてを編集できるようなテキストボックスを並べる。
2行目には装備特性を並べる。
編集ウィンドウは縦軸を固定する必要はない。
編集ウィンドウの外を押すとキャンセルボタンと同じようにメインウィンドウを消したい。
